# Search Result: Can you summarize what waste dataare available on the KDF?

## 🧠 Answer Summary

The KDF hosts several datasets that can be used to assess waste biomass. It includes the “Modeled Output and Other Data from Biomass from the Forested Land Base” dataset, which provides ForSEAM and BioSUM model outputs and USDA Forest Inventory data specifically used to calculate waste biomass from the forested land base. The “BT2 – Primary Forest Resources” dataset supplies raw forest resource data for 2012‑2030 that can support waste‑feedstock analysis. The 2012 Billion‑Ton Update FAQ notes that the KDF will allow users to upload their own loss and waste assumptions, enabling custom waste‑data calculations. Other datasets (e.g., forestland biomass production cost data) support related cost analyses but do not directly provide waste quantities.

2021 Forestland Biomass Production Costs for the 2024 Billion Ton Analysis
This dataset contains harvesting, chipping, and production cost data for forestland production by region and forest harvest system. The dataset supports Biomass from the forested land base analysis in the BT23 (Davis et al., 2024) and subsequent modeling using the Forest Sustainable and Economic Analysis Model (ForSEAM). The cost data was updated by Burton English and is in 2014 dollars and 2021 dollars. Data sources can be found in the accompanying PDF, ‘2021 Biomass Production Costs for the 2024 Billion Ton Analysis’, and the details can be found in the accompanying Microsoft Word file.
