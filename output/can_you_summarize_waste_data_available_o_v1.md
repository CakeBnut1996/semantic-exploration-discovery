# Search Result: Can you summarize waste data available on the KDF?

## 🧠 Answer Summary

The KDF provides several waste‑biomass data resources: a modeled output set that uses ForSEAM and BioSUM models together with USDA‑FS forest inventory data to calculate waste biomass from the forested land base; raw primary forest‑resource data covering 2012‑2030 that underpins those waste calculations; cost data for forestland biomass production (harvesting, chipping) that supports the waste‑biomass analysis; and documentation on feedstock losses and conversion efficiencies that clarify how reported “billion‑ton” figures differ from biorefinery‑throat amounts. These datasets can be accessed via the BT23 Data Portal and related KDF pages.

2021 Forestland Biomass Production Costs for the 2024 Billion Ton Analysis
This dataset contains harvesting, chipping, and production cost data for forestland production by region and forest harvest system. The dataset supports Biomass from the forested land base analysis in the BT23 (Davis et al., 2024) and subsequent modeling using the Forest Sustainable and Economic Analysis Model (ForSEAM). The cost data was updated by Burton English and is in 2014 dollars and 2021 dollars. Data sources can be found in the accompanying PDF, ‘2021 Biomass Production Costs for the 2024 Billion Ton Analysis’, and the details can be found in the accompanying Microsoft Word file.
